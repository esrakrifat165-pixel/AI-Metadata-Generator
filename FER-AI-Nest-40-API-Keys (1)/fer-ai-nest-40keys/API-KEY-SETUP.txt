FER AI Nest - 40 API Key Rotation

Providers:
- Gemini: GEMINI_API_KEY_1 ... GEMINI_API_KEY_10
- OpenAI/ChatGPT: OPENAI_API_KEY_1 ... OPENAI_API_KEY_10
- Claude: ANTHROPIC_API_KEY_1 ... ANTHROPIC_API_KEY_10
- Grok: XAI_API_KEY_1 ... XAI_API_KEY_10

Backward compatibility:
- Existing GEMINI_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY, and XAI_API_KEY are treated as logical slot 1 when the numbered _1 variable is not present.

Local development:
1. Replace the files in your project with the files in this package.
2. Keep your existing .env.local key; do NOT paste real keys into source files.
3. Add additional keys as environment variables or use the API Keys screen locally.
4. Restart the dev server after editing .env.local.

Vercel:
Add the numbered variables in Project Settings -> Environment Variables. Keep the variables server-side. Redeploy after adding or changing them.

Rotation:
The server tries keys in slot order and moves to the next configured key for quota/rate-limit/authentication errors.

Important:
Multiple API keys do not automatically create additional provider quota. Quota/billing is controlled by the provider/project/account. Use keys only where the provider permits the usage.
